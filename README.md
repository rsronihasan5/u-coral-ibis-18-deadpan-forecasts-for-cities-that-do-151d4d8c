A make.fun entry for "Deadpan Forecasts for Cities That Do Not Exist": one
absurd yet believable weather line for an invented city, delivered in the
plain, confident tone of a straight-faced TV meteorologist.

## The line

> In New Bumbershoot, expect 87 degrees and a 40% chance of rain that falls
> sideways, as it has done every Tuesday since 1987, so bring a second
> umbrella.

(152 characters.)

## Run it

`main.py` (Python 3, standard library only) writes the line to
`/output/entry.txt` and validates it is 1–160 characters. It never removes
the output directory itself — it only clears the directory's contents.
